- **URL** — required and must parse with `new URL`. Email is optional; if present it must match `^[^\s@]+@[^\s@]+\.[^\s@]+$`. `src/utils/validation.ts`.

- **Localized text** — a map counts as present when any value trims to non-empty. Read order: requested language, then `en`, then the first value. `src/utils/agentHelpers.ts`.

## Agents

- **Empty agent** — one trigger `{ type: 'endpoint', config: null }`; provider `emporix_openai`; temperature `0`; max tokens `0`; additional params `null`; recursion limit `20`; memory on; enabled; metadata version `0`; type `custom`. `src/utils/agentHelpers.ts`.
- **Config fill-in** — missing triggers become that endpoint trigger; missing provider object becomes `emporix_openai` with temperature `0`, max tokens `0`, additional params `null`; missing recursion uses `|| 20` (so `0` is treated as missing); missing memory becomes `true`; missing enabled becomes `false`; metadata version defaults to `1`. `src/utils/agentHelpers.ts`.
- **Versioned fields** — `name`, `description`, `icon`, `tags`, `enabled`, `requiredScopes`, `templatePrompt`, `userPrompt`, `llmConfig`, `triggers`, `mcpServers`, `nativeTools`, `agentCollaborations`, `maxRecursionLimit`, `enableMemory`, `outputFormat`. `id` and `type` are not versioned. `src/utils/agentVersionHelpers.ts`.
- **Rollback** — refused (`null`) unless live metadata exists, live version is a number, snapshot name has a non-blank localized value, `userPrompt` is non-blank, triggers are non-empty, and `llmConfig` has a non-blank model and a provider. Applied defaults: description `{}`, MCP and native tools and collaborations `[]`, recursion `20`, memory `false`, enabled `false`, tags `[]`, required scopes `[]`, mixins `{}`. Live version number is kept; `changeNote` is the caller’s note. Pinned in `src/utils/agentVersionHelpers.test.ts`.
- **Version list** — current row plus `versions` snapshots, highest version first. Same version: current row before the snapshot. Missing metadata version is `0`. `src/utils/agentVersionHelpers.ts`.
- **Version diff** — object keys are sorted before compare, so key order is not a change. `undefined` compares as empty; `null` as `null`. Scalars diff as text; other values as pretty JSON. Unchanged context keeps 3 lines; a block hides lines only when at least 2 would be hidden. `src/utils/agentVersionHelpers.ts`.
- **Author label** — trimmed first + last name, else id, else the system label when type is `SYSTEM`, else empty. `src/utils/agentVersionHelpers.ts`.
- **Collaboration row** — valid only when agent id and description both trim non-empty. An agent id without a description is invalid. A description without an agent id is invalid. Options exclude the current agent and ids already used on other rows. Rows sort by localized name. A trailing empty row is shown once the last row has an agent id. Persist keeps only valid rows, description trimmed. `src/utils/agentCollaborationHelpers.ts`.
- **Additional LLM params** — blank JSON saves `null`. Non-blank must be a JSON object (not an array); errors `invalid_json` or `must_be_object`. Empty object also saves `null`. `src/utils/llmAdditionalParamsHelpers.ts`.
- **Model after provider switch** — self-hosted keeps the remembered free-text model or `''`. Catalog providers: keep current id/name match, else remembered match, else the first model after name sort (`localeCompare`, base sensitivity). Empty catalog falls back to current then remembered text. `emporix_openai` shares OpenAI models. `src/utils/llmModelHelpers.ts`.
- **Output JSON Schema** — blank text is valid. Otherwise it must be a non-array object, contain one of `$ref`, `$defs`, `definitions`, `type`, `properties`, `items`, `oneOf`, `anyOf`, `allOf`, `not`, `enum`, `const`, `if`, `$schema`, and pass Ajv `validateSchema` (`strict: false`). Error keys `output_format_invalid_json` and `output_format_invalid_json_schema`. `src/utils/validateJsonSchema.ts`.

- **Teams tool form** — `teamId` and `tenantId` required; allowed operations non-empty. Empty Teams draft may preset `tenantId`. - **Commerce trigger config** — `events` (string array), optional `filter` DSL, optional `eventScopes` (non-blank strings only; omitted when empty). `src/utils/agentFilterDslHelpers.ts`.
- **Filter DSL** — leaf `{ left, op, right? }` or compound `{ op, conditions }`. Leaf ops `$eq` `$ne` `$in` `$notIn` `$exists` `$notExists` `$isEmpty` `$notEmpty`, mapped to UI `equals` `notEquals` `in` `notIn` `exists` `notExists` `isEmpty` `notEmpty`. Logical ops `$and` `$or`. `exists` / `notExists` / `isEmpty` / `notEmpty` omit `right`. `in` / `notIn` need a non-empty string array. Other value ops need a string, number, or boolean, not `''`. `left` must be a non-blank string. Compound conditions must be a non-empty array. Default leaf is `{ left: '', op: '$ne', right: '' }`. `null` filter is invalid. Nested compounds are valid only if every node is. One leaf is stored as a leaf, not wrapped in `$and`. Form editing is allowed for null, a leaf, or a compound whose children are all leaves. `src/utils/agentFilterDslHelpers.ts`.
- **Multi-value text** — comma-split, trim, drop empties. `src/utils/agentFilterDslHelpers.ts`.

## Tools

Every filter field key must match the same pattern. Provider required. `emporix_openai` needs nothing else. `openai` needs model, dimensions 128–4096, and a token id. `self_hosted_ollama` needs those plus a URL and a token id. Other providers fail the form. `src/utils/toolConfigHelpers.ts`, `src/utils/ragEmporixToolHelpers.ts`, `src/types/Tool.ts`.
- **RAG Emporix defaults** — entity `product` and provider `emporix_openai` when missing. On load, nested `emporixNativeToolConfig` wins for prompt, entity, indexed fields, and filter fields; embedding objects merge with nested keys over top-level. Save drops invalid keys and blank names/descriptions. Indexed-field picker hides a key that equals, is a parent of, or is a child of another selected key (`a` vs `a.b`). `src/utils/toolConfigHelpers.ts`, `src/utils/ragEmporixToolHelpers.ts`.
- **RAG custom form** — prompt, max results integer 1–100 (default 5 when nullish), database URL, collection name, database token id, embedding model, embedding token id. Default DB type `qdrant`, entity `product`. `src/utils/toolConfigHelpers.ts`.
- **Search tool** — entity must be `customer` or `legal-entity`. Max results integer 1–10; anything else becomes 5. Unknown entity becomes `customer`, except legal-entity aliases. Prompt kept only when non-blank. `src/utils/toolConfigHelpers.ts`.
- **File tool** — form always valid once name/type/id pass. Save config is `{}`. Catalog injection removes every `type: 'file'` tool and id `file_generator`, then appends one enabled `file_generator`. `src/utils/toolConfigHelpers.ts`, `src/utils/agentToolsHelpers.ts`.
- **Unknown tool type** — form valid once name, type, and (on create) id are non-blank. `src/utils/toolConfigHelpers.ts`.
- **Empty tool** — id and name and type `''`, config `{}`, enabled. `src/utils/toolHelpers.ts`.
- **Predefined domain tools** — one `predefined` server per domain. Tool names sorted. Last tool removed deletes that server. Checking an existing tool is a no-op. `src/utils/agentToolsHelpers.ts`.
- **Managed MCP on an agent** — attach stores `{ type, mcpServer: { id } }` with no tool list. Dynamic tool list omitted when it equals the server’s enabled tool names (meaning all). Empty selection does not detach. Reconcile flips type to the catalog type; custom reconcile drops the tool list. `src/utils/agentToolsHelpers.ts`.

## Logs, jobs, import

- **Request log** — messages have severity, text, timestamp, agent id, optional version, optional request id, optional business flag. A request groups a session, trigger agent, collaboration agents, token counts, and duration. `src/types/Log.ts`.
- **Inbound text** — first message whose text contains `Agent receive streaming request:`, `Agent receive request:`, `Processing Slack message for user:`, `Processing routed Slack message`, or `Processing Teams message for conversation`, then the pattern capture. Streaming requests use the streaming extractor. Response text prefers `Agent final response:` or Slack/Teams “sent successfully” captures. Same log line means same timestamp, message, and agent id. Display id is `agentId` or `agentId (vN)` when version is present. `src/utils/logHelpers.ts`.
- **List query** — three namespaces: `r` requests, `j` jobs, `s` sessions. Page size must be 10, 25, 50, or 100; otherwise 10. Default sort is descending: requests `lastActivity`, jobs `createdAt`, sessions `metadata.modifiedAt`. Request `agentId` filters and sorts as `triggerAgentId`. Date params are `YYYY-MM-DD` and must be a real calendar day. API date filter is a same-local-day range `(>="start" AND <"end")` with start `00:00:00.000` and end `23:59:59.000`. Severity filters are sent as 10/20/30. Job type filters `IMPORT`/`EXPORT`/`AGENT_CHAT` become `import`/`export`/`agent_chat`. Table filter `agentId` maps to API field `id` unless overridden. Cursor pages expose `next` / `prev`. `src/utils/logListQuery.helpers.ts`, `src/utils/dataTableHelpers.ts`, `src/utils/dateHelpers.ts`, `src/utils/filterHelpers.ts`, `src/types/CursorPagination.ts`.
- **Session efficiency** — requests per session: under 3 excellent, 3–5 good, 5–8 moderate, above 8 poor. `src/constants/chartConstants.ts`.
- **Import details** — legacy token note shows only when every `ENABLED` or `DISABLED` item has no details, and there is at least one such item. Failure is any item in `FAILED`. Detail text uses i18n key `import_details_` plus the code. `src/utils/importDetails.ts`.
